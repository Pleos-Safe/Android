# MILESTONE 역할분담

두 사람 모두 피그마에서 맡은 화면을 임시 데이터로 먼저 구현하고, 같은 담당자가 실제 기능까지 연결한다. 각자 자기 화면의 전체·분할·좁은 창(L 계열 참고), 로딩·빈 결과·오류 상태를 맡는다.

## 개발자 A · 일상 주행과 운전습관

장소에 들르지 않은 출퇴근 한 번으로 시연할 수 있다. 주행을 기록하고, 주차 후 리포트를 확인하고, 조건을 충족하면 안전운전 카드를 얻어 연다.

### 1. 디자인

- 여정 목록·상세·방문 지도·카드별 기억, 운전습관 리포트와 데이터 부족 화면(F 계열, H07).
- 카드 앞뒷면·프레임·효과·선반과 공용 카드 공개 화면(C06·C06S·C07·C07S·C08·C09·C09G·C09S). 컬렉션·필터·정렬·상세·미공개 보관함·대표 카드 선택(D 계열).
- 온보딩·저장 선택·설정·데이터 관리·삭제(G 계열), 기록 조회 실패와 삭제 결과 재확인(H08·H08D·H08DQ).

### 2. 기능 개발

- 속도·기어·플랫폼 조작 제한을 수신해 공통 차량 상태와 조작 가능 여부를 판단한다. 여정의 시작과 종료, 동의한 주행 기록의 저장·복원을 맡는다.
- 직접 기록한 여정으로 운전습관을 분석하고 리포트를 만든다. 근거가 부족하면 평가를 보류한다. 조건을 충족하면 안전운전 달성과 카드 획득·성장을 같은 여정에 한 번만 저장한다.
- 기록 조회, 카드 공개·보관·대표 선택을 맡는다. 저장 선택과 개별·전체 삭제를 처리하고, 삭제 후 남은 근거에 맞춰 카드·기억·미공개 목록·대표 선택을 갱신한다.

## 개발자 B · 장소 탐색과 방문

여행 홈에서 장소 한 곳을 찾아 목적지나 경유지로 추가한다. 도착 후 방문을 확인하고, 해당 장소의 카드를 얻어 공용 공개 화면에서 연다.

### 1. 디자인

- 여행 홈의 주행 전·주행 중·도착·주차 후 결과(A 계열). 공용 버튼·칩·탭·입력창·헤더·다이얼로그·시트와 공용 지도.
- 장소 추천·목록·상세, 지도·검색·핀·장소 선택, 목적지·경유지 확인과 내비 요청 결과(B 계열).
- 도착 후보·방문 근거·사용자 확인·저장·중복·보류(C01·C02·C03·C04·C05·C05P). 위치·조작 제한·장소·내비 안내와 방문 저장 결과 재확인(H01·H02·H03·H05·H06·H08M·H08MQ·H09).

### 2. 기능 개발

- FusedLocation 위치 연동과 장소 추천·지도 검색·선택을 맡는다. Pleos 에뮬레이터에서 SDK 지원 여부와 위치 권한을 확인하고 위치를 수신한다. 위치를 얻지 못하면 지도에서 직접 탐색할 수 있게 한다. NaviHelper로 목적지·경유지 설정과 경로 조회를 처리한다. [위치 SDK 개발 가이드](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/FusedLocation/intro)
- 도착 후보의 위치·체류 근거와 공통 주차·조작 가능 상태를 확인하고 사용자에게 방문 여부를 묻는다. 저장에 동의했고 방문이 확인되면 B가 방문 기록과 그에 따른 장소 카드 획득·성장을 함께 저장한다. 중복·보류·결과 미확인 후 재조회까지 B가 처리한다.
- 홈에 경로·방문 결과·직전 여정의 운전습관 요약·대표 카드·미공개 카드를 표시한다. 사용자가 주차 후 열기를 선택하면 공용 공개 화면을 연다.

## 두 흐름이 만나는 곳

- 같은 주행에는 하나의 여정 ID를 쓴다. A가 여정을 관리하고 B는 방문이 발생한 여정 ID를 사용한다. A가 기존 차량 상태(VehicleRepository)에서 주차·조작 가능 여부를 판정하면 두 흐름 모두 그 값을 읽는다.
- A가 공용 카드 저장·공개 기능을 맡는다. B는 방문 저장 시 그 기능을 직접 사용해 장소 카드를 반영하고, A는 안전운전 달성 저장 시 안전운전 카드를 반영한다. 저장 성공 시 소유를 확정하고, 공개 상태는 사용자가 주차 중 카드를 열 때 갱신한다. 홈·기록·컬렉션은 저장된 결과를 읽는다.
- 디자인 단계에서 예시 여정 ID와 두 종류의 카드 결과로 화면을 맞춘다. A의 카드 컴포넌트와 B의 지도 컴포넌트는 양쪽에서 재사용한다. 기능을 개발할 때 A는 장소 방문 없이 출퇴근 한 건으로, B는 예시 여정 ID와 주차 상태로 각자 자기 흐름을 끝까지 확인할 수 있다.
