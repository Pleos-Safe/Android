# 차곡차곡 색상 역할

앱의 공통 액션·링크·선택 탭은 현대 Active Blue, 보조 강조와 설명은 Sky Blue를 사용한다.
색상 기준은 [현대자동차 공식 CI 색상](https://www.hyundai.com/kr/ko/info/ci/ci-color)이다.

| 기준 색상 | 값 | 앱에서의 역할 |
| --- | --- | --- |
| Hyundai Blue | `#002C5F` | 액션 위 글자, 선택한 칩 배경 |
| Active Blue | `#00AAD2` | 주요 버튼, 링크, 선택 탭과 현재 위치 |
| Sky Blue | `#AACAE6` | 보조 글자, 장식의 보조 강조 |
| White | `#FFFFFF` | 주요 글자 |
| Light Sand | `#F6F3F2` | 브랜드 장식의 밝은 마무리 |

차량용 어두운 배경은 Hyundai Blue에 검정을 혼합한 **앱 파생톤**이다.
예를 들어 기본 배경 `#000F21`, 화면 그라데이션 `#000B18`–`#001A39`, 패널 `#001630`은
공식 CI의 추가 색상으로 제시하지 않는다. 테두리와 비활성 색상도 공통 파생 토큰을 사용한다.
컬렉션 전시 배경 역시 이 토큰을 사용하며 별도의 고정 팔레트를 두지 않는다.

주요 버튼의 Hyundai Blue 글자와 Active Blue 배경 대비는 **5.03:1**이다.
Active Blue 링크와 기본 배경은 **7.04:1**, Sky Blue 설명과 패널은 **10.63:1**이다.
이는 sRGB 상대 휘도로 계산한 정적 토큰 값의 대비이며 실제 화면 검수를 대체하지 않는다.

방문 카드팩 지도의 보라색 여섯 단계와 방문 테두리, 카드 등급의 Sand·Gold,
현대 카드의 Hyundai Blue·E-pit Mint, 강화 결과와 경고를 구분하는 신호색은 기능 의미를 유지한다.
공통 브랜드 장식은 상태 경고 색상을 가져다 쓰지 않고 파랑 계열과 밝은 중립 토큰을 사용한다.
