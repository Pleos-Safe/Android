# 차곡차곡 브랜드 에셋

최종 심볼은 한글 `차곡`의 획을 자동차의 지붕·차체·바퀴와 연결한 가로형 로고다. 선택한 02번 시안을 기준으로 한다. 앱 이름과 외부 워드마크는 `차곡차곡`을 사용한다.
앱 아이콘은 Hyundai Blue 바탕에 흰 심볼을 배치한다. 색상 역할은 [디자인 색상](../architecture/DESIGN_COLORS.md)을 따른다.

- `car-logo.svg`: 밝은 배경에 사용하는 블루 심볼
- `car-logo-on-dark.svg`: Hyundai Blue 배경 위의 흰 심볼 참조
- `car-logo-app-icon.svg`: 둥근 배경에 배치한 앱 아이콘 참조
- `chagok-card-back.svg`: 카드 뒷면의 벡터 원본

심볼의 가로세로 비율은 5:3이다. 가로형을 정사각형으로 늘이지 않고, 가운데 정렬해 사용한다. `곡`의 받침 ㄱ과 바퀴 안쪽의 빈 공간을 유지한다.
런처와 공통 로고, 빈 컬렉션 카드, 카드 뒷면의 제품 원본은 Android 벡터다. SVG는 같은 기하를 공유하는 문서용 참조다.
런처의 심볼은 adaptive icon의 안전 영역 안에 배치한다. 카드 뒷면은 둥근 외곽 모서리 외에는 불투명하다.

카드팩은 `feature/collection/src/main/res/drawable-nodpi/pack_{busan,seoul,jeju,hyundai}.png`에 저장한다.
네 가지 팩에 공통으로 사용하는 편집 기준은 다음과 같다.

> 기존 지역 카드팩의 상단 차곡차곡 워드마크 옆 심볼을 참조 이미지의 흰 차량형 차곡 로고로 교체한다.
> 차곡의 글자 획과 지붕·차체·바퀴가 연결된 가로형을 유지하고 별도 사각 타일을 추가하지 않는다.
> 차곡차곡 및 지역별 한글, 포장 가장자리, 지역 풍경, 자연색, 재질, 구도는 유지한다.
> 포장 내부는 불투명하게, 외부만 투명하게 처리한다.
